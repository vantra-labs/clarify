# Установщик Clarify

Один файл `Clarify_Setup_<версия>.exe`, который отдаём людям. Никакого мастера
«Далее — Далее — Готово»: окно установщика нарисовано на Flutter в том же
визуальном языке, что и само приложение.

## Как собрать

```powershell
cd installer
powershell -ExecutionPolicy Bypass -File .\build_installer.ps1
```

Готовый файл появится в `installer/dist/`.

Флаг `-SkipApp` не пересобирает само приложение — удобно, когда правишь только
установщик:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_installer.ps1 -SkipApp
```

Что нужно на машине сборки: Flutter, 7-Zip (`C:\Program Files\7-Zip\7z.exe`) и
Visual Studio с компонентом C++ — тот же, без которого не собирается и само
приложение. Ничего дополнительно устанавливать не требуется.

## Из чего он состоит

```
installer/
  bootstrap/          нативная оболочка (C++), она же деинсталлятор снаружи
    bootstrap.cpp     распаковка себя во временную папку и запуск установщика
    bootstrap.rc      иконка, манифест, свойства файла
    bootstrap.manifest  asInvoker (без UAC) + DPI + UTF-8
  clarify_installer/  сам установщик — приложение на Flutter
    lib/install_engine.dart  вся работа с системой (файлы, реестр, ярлыки)
    lib/ui/                  экраны и виджеты
  build_installer.ps1 сборка одного файла из всего перечисленного
  dist/               результат
```

### Почему устроено именно так

Приложение на Flutter — это не один exe, а exe плюс библиотеки и папка `data`.
Чтобы отдать людям **один** файл, снаружи стоит маленькая нативная оболочка: к
её концу дописан zip, а последние 24 байта — служебная запись (сигнатура
`CLRFYPK1`, смещение архива, его размер). Оболочка находит по ней архив внутри
себя, распаковывает во временную папку системным `tar.exe` (есть в Windows 10 и
11 из коробки) и запускает установщик, а после его выхода убирает за собой.

Собственного интерфейса у оболочки нет — всё, что видит человек, рисует
установщик. Единственное исключение: окно с ошибкой, если файл повреждён или
его порезал антивирус. Молча закрыться, ничего не сказав, — худший вариант.

## Что делает установка

- Ставит в `%LOCALAPPDATA%\Programs\Clarify` — **без прав администратора**,
  поэтому запрос UAC не появляется вовсе.
- Создаёт ярлык в меню «Пуск». Он обязателен: без ярлыка Windows не показывает
  уведомления приложения (требование `local_notifier`, см. `main.dart` в
  `frontend/`).
- По желанию — ярлык на рабочем столе и автозапуск вместе с Windows
  (`HKCU\...\Run`, с аргументом `--autostart`, который приложение понимает и
  стартует свёрнутым в трей).
- Регистрирует программу в «Программах и компонентах»
  (`HKCU\...\Uninstall\Clarify`): название, версия, издатель, размер, иконка,
  строки обычного и тихого удаления.
- Кладёт рядом с программой `Clarify_uninstall.exe` — облегчённую сборку
  установщика без упакованного приложения внутри (13 МБ вместо 54).

Установка поверх существующей версии сначала закрывает запущенное приложение и
удаляет старые файлы целиком: иначе от предыдущей версии остались бы библиотеки,
которых уже нет в новой, а Flutter при несовпадении движка и ассетов падает
молча, без окна.

## Тихий режим

Для развёртывания на несколько машин и для автоматических проверок:

```powershell
Clarify_Setup_1.0.0.exe --silent [--dir=C:\Path] [--desktop-shortcut] [--autostart]
Clarify_uninstall.exe --uninstall --silent
```

Код возврата честный: `0` — получилось, `1` — нет (причина уходит в stderr).
В тихом режиме галочки не наследуются от предыдущей установки: что указали
флагами, то и будет.

## Чего здесь намеренно нет

- **Подписи кода.** Пока файл не подписан сертификатом, Windows покажет синий
  SmartScreen при первом запуске у любого, кто скачает. Это не лечится
  красотой установщика — нужен сертификат на юрлицо или ИП.
- **Установки для всех пользователей** (`HKLM`, `Program Files`). Она требует
  прав администратора; сейчас сознательно выбран вариант «для себя, без UAC».
- **Автообновления.** Обновление ставится поверх запуском нового установщика.
